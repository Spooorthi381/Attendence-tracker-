# Attendence-tracker-
Attendance Tracker is a simple Python project that helps you add students, record daily attendance in DD-MM-YY format, and automatically marks Sundays as holidays. It summarizes daily present, absent, and total students, making attendance management easy and organized.
•	Add and remove student names
•	Mark present/absent for any date
•	Automatic holiday marking for Sundays
•	View attendance summaries and detailed reports
How to Use
1.	Run the Python script or Jupyter notebook.
2.	Add students to the class list.
3.	Mark attendance for students each day using DD-MM-YY format.
4.	View daily summaries and attendance history.
Requirements
•	Python 3.x
•	(Optional) Jupyter Notebook for notebook version
